# Log Manager

Log Manager is a VS Code extension for finding and managing `console.*` statements across JavaScript and TypeScript projects.

The first release focuses on a visual dashboard for workspace-wide log inspection, filtering, navigation, insertion, and safe cleanup.

## First Release Scope

- JavaScript, TypeScript, JSX, TSX, Vue SFC script blocks, `.mjs`, and `.cjs`.
- `console.log`, `console.info`, `console.debug`, `console.warn`, `console.error`, and `console.table`.
- Workspace scan, search, filters, previewable destructive operations, and editor commands.

## Development

```bash
npm install
npm run compile
npm test
```
